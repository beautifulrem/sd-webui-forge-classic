# Anima LoRA 阶段介入

[English](README.md) | 中文

Anima LoRA 阶段介入是一个 Forge/WebUI 插件，用于控制 Anima LoRA 在采样过程中的介入时间。它可以让 LoRA 只在构图、人物特征或画风阶段生效，也可以为底图阶段和高分辨率修复阶段分别设置不同的调度。

## 功能

- 面向 Anima 模型的 LoRA 阶段介入，不修改模型文件。
- 内置构图阶段、人物特征阶段、画风阶段模板。
- 支持介入和禁止两种行为：让 LoRA 只在某阶段生效，或在某阶段强制为 0。
- 支持根据 Shift 自动调整介入时间。Shift 越高，窗口会轻微后移。
- 底图和高分辨率修复可分开设置。高分辨率修复可继承底图设置，也可使用独立面板。
- 高分辨率修复阶段可禁用全部 LoRA，或禁用指定完整 LoRA 标签。
- 支持单 LoRA 模板覆盖，同一提示词中的不同 LoRA 可使用不同阶段模板。
- 支持模板保存、重命名、删除，以及由基础预设组合生成自定义模板。
- 设置页提供界面语言切换：`zh` 和 `en`。

## 安装

已内置于 Forge Neo Remi：打开 txt2img 或 img2img，展开 **Anima LoRA 阶段介入** 面板。

## 基础使用

1. 勾选 **启用阶段介入控制**。
2. 选择目标范围：
   - 自动识别 Anima LoRA：只作用于检测为 Anima 的 LoRA。
   - 提示词中的全部 LoRA：作用于提示词内所有 LoRA 标签。
   - 仅目标列表：只作用于目标框内填写的名称。
3. 选择画风、构图或人物特征阶段模板。
4. 一般建议保持 **根据 Shift 自动设置介入时间** 开启。
5. 正常生成，插件会在采样期间动态调整 LoRA patch 强度。

## 时间参数

- **开始比例** 和 **结束比例** 是采样进度 `0` 到 `1`，即在完整噪声调度中的位置，因此高分辨率修复或图生图会从中途开始（约为 `1 - 重绘幅度`）。
- 关闭自动时间时，面板的单一开始/结束窗口取代模板的各阶段。仅包含“禁止”的模板，该窗口禁止 LoRA；否则该窗口内介入。
- **峰值比例** 是曲线最强的位置。
- **阶段强度倍率** 会乘到最终 LoRA 强度上，自动时间下同样生效。
- **强度曲线** 控制强度随采样进度变化的方式：平滑、保持、线性三角、前强后弱、后强前弱。
- **Shift** 会从 Forge 的 Shift / Distilled CFG 控件读取。自动模板会根据当前 Shift 调整窗口。

## 单 LoRA 模板

每行一个规则：

```text
lora_name=模板名
<lora:name:0.8>=模板名
```

没有填写规则的 LoRA 使用面板上方选择的模板。

## 模板管理

模板管理可以保存当前底图面板为模板、重命名自定义模板、删除自定义模板，也可以用基础阶段预设组合生成模板。内置模板不能覆盖、重命名或删除。

## 设置的保存与恢复

启用后生成的图片会在 infotext（PNG 参数）中以 `Anima LoRA stage ...` 键记录本次使用的全部面板设置：目标范围与目标列表、面板权重、模板、单 LoRA 模板、自动时间、实际使用的开始/结束/峰值比例（自动时间下为按 Shift 计算的值）、阶段强度倍率和强度曲线；开启高分辨率修复时还记录是否使用独立面板（独立时连同其设置）以及高分辨率修复的 LoRA 禁用设置。粘贴 infotext（提示词旁的粘贴按钮，或 PNG Info 的发送按钮）会恢复这些面板设置，相同提示词和种子即可复现图片。

- 提示词中的 LoRA 标签按原样保留（如 `<lora:x:0.6>`）；非 0 的面板权重在生成时替换了该权重，它单独记录为一个键，并随面板一起恢复。
- 选项以固定代码记录（`auto`/`all`/`targets`、`smooth`/`triangle`/…、`none`/`all`/`selected`），中文界面和英文界面可以互相粘贴对方的图片。
- 自定义模板按名称记录。粘贴端没有该模板时，模板下拉框保持不变，并在控制台给出警告。
- 此前生成的图片只有一行 `Anima LoRA Stage Scheduler` 摘要；粘贴这类图片时面板保持不变。

## 语言设置

进入 **设置**，找到 **Anima LoRA Stage Scheduler / Anima LoRA 阶段介入**，选择 `zh` 或 `en`，然后 Reload UI。

## 注意

- 为了兼容已有模板，内置模板 key 会保持稳定，所以英文界面下部分模板名仍可能保留中文。
- 插件只在采样时控制 LoRA patch 强度，不修改 checkpoint 或 LoRA 文件。
- 启用时，插件会在本次生成期间把 Forge 切换为在线（on-the-fly）LoRA，因为每步变化的强度无法合并进权重。采样会比合并 LoRA 慢（Forge 也会提示这一点）；生成结束后恢复原设置。
- 建议先用中等 LoRA 权重测试，避免同时堆叠过多强介入模板。
