# Anima 画师串调度混合

Anima 画师串调度混合是一个 Forge Neo 扩展，用来让 Anima 的画师标签更接近 SDXL 画师串的混合方式。

它不会把多个画师名直接交给 Anima 的 LLM 文本编码器一起上下文化理解，而是把每个画师行独立编码，再在采样时把这些画师条件注入并混合到 Anima 的 cross-attention 中。核心思路参考 [An1X3R/Anima-Artist-Mixer](https://github.com/An1X3R/Anima-Artist-Mixer)：拆分画师、独立编码、在 cross-attention 混合，而不是修改文本编码器层。

特别感谢 **An1X3R/Anima-Artist-Mixer** 与 **汐浮尘/utowo** 的原始独立编码和 cross-attention 混合设计。

## 功能

- 每个画师独立一行，可设置画师提示词、权重、介入 block、介入时间、峰值、曲线和阶段预设。介入时间（开始/结束）按采样步数的比例计算。
- 基础提示词中的提示词编辑（`[a:b:N]`、`[a|b]`）会像主提示词一样逐步解析，应用到每个画师分支。
- 画师单元格支持直接写行内倍率，例如 `(wlop:1.2)`、`[wlop:0.8]` 或 `wlop:1.2`；该倍率会与该行 `权重` 相乘。
- 底图与高分辨率修复画师串分离。高分辨率修复默认关闭独立设置，关闭时继承底图。
- 设置变化时会自动保存当前 UI 状态，刷新 UI 或重启 Forge 后会直接恢复上次设置。
- infotext 会记录生成时参与混合的画师行和控件，粘贴图片参数即可恢复面板（见“Infotext 与粘贴”）。
- 模板保存、应用、重命名和删除。应用模板后所有参数仍可继续手动修改，也可跨会话复用。
- 支持一键全部恢复内置默认设置，不会删除已保存模板。
- 可选择在高分辨率修复阶段不启用画师串混合，只让底图阶段使用混合。
- 模板使用稳定内部值保存，可在中文/英文 UI 之间互相应用。
- 优化预设、组合模式、融合模式、曲线、阶段、模板应用目标等选项会随界面语言显示。
- 性能、平衡、质量三个优化预设，默认平衡。
- 设置里支持中英文 UI，面板顶部说明也可切换语言。
- 文本编码缓存，重复画师和提示词时减少编码开销。
- 默认使用更接近参考项目的 `输出平均 + 插值融合`，同时保留更稳的 `保真增量`，方便在需要保守混合时切换。

## 行控制

建议每行只放一个画师提示词。这样每个画师都能独立控制权重、层数、时间、曲线和阶段。为了迁移旧画师串，逗号分隔仍然可用，但每行一个画师更容易得到可预测的调度效果。

`层数` 始终按 28 层（2B）布局填写。在加深后的 2.9B（40 层）和 3.8B（52 层）模型上，每个 2B 层也会选中由它复制插入的层，所以同一范围在任何模型上都覆盖相同的深度：`10-18` 在 2.9B 上是第 15-27 层，在 3.8B 上是第 20-36 层。（DAVE 的层列表不同：它只把每个 2B 层映射到原始层，不包括复制层。）大于 27 的序号会被忽略，因此 `0-51` 在任何模型上都选中全部层。留空时使用优化预设的默认值（平衡与质量为 `0-51`，即全部层；性能为 `10-18`）；若填写的内容选不中任何层（只有无效部分或大于 27 的序号），该画师会被跳过，并在控制台给出警告。其他层数的模型直接使用自身的层序号。

`阶段 + Shift + 自动Shift` 会用类似 Anima LoRA Stage Scheduler 的方式重写该行时间窗口：构图偏早，人物居中，画风偏晚。选择自定义之外的阶段时，开始、结束和峰值会立刻刷新。之后如果想手动微调，再关闭自动Shift即可。

## 设置与模板

修改任意主要控件时（文本框在离开或按回车后），插件会把该标签页的当前状态写入本地 `artist_mixer_current_settings_txt2img.json` 或 `artist_mixer_current_settings_img2img.json`，文生图与图生图各自保留自己的面板。这些文件位于 `<数据目录>/extension-data/anima-artist-scheduled-mixer/`（与已保存的模板 `artist_mixer_templates.json` 放在一起），不在插件文件夹里，只用于刷新 UI 或重启后恢复你的上次面板状态。尚无自己文件的标签页会从旧版本两个标签页共用的 `artist_mixer_current_settings.json` 开始。

点击 `全部恢复默认` 会清除当前设置文件并恢复插件内置默认值。该操作不会删除模板文件。

高分辨率修复页签中有 `高分辨率修复不启用画师串混合`。开启后，插件在 Hires. fix 阶段不做混合：不会为该阶段安装任何覆盖，高分修复保持原始生成逻辑。

## Infotext 与粘贴

实际做了混合的生成会在 `Anima Artist Mixer` 摘要旁记录面板设置。每个键是一个 JSON 值，使用与模板相同的内部值（不是界面上的本地化标签）：

- `Anima Artist Mixer options`：会影响出图的全局控件：`strength`、`optimization`、`combine`、`fusion`、`apply_uncond`、`hires_independent`、`disable_hires_mixing`。
- `Anima Artist Mixer base`：参与混合的底图画师行（已启用且填写了画师的行；未启用行和空行不记录），每行为 `[artist, weight, blocks, start, end, peak, curve, stage, auto_shift]`。开始/结束/峰值是按该遍 Shift 得到的值。
- `Anima Artist Mixer hires`：高分辨率修复画师行，格式相同；只在高分修复阶段使用独立画师串混合时记录。

粘贴这些参数（提示词旁的粘贴按钮，或 PNG 信息页的发送按钮）会恢复面板，中英文界面可互相粘贴：开启画师串混合，设置记录的控件，按记录逐行填入画师行（行数随之调整），并像手动修改一样保存该标签页的当前设置。粘贴不会改动模板、模板下拉框和文本编码缓存开关。infotext 里没有高分画师行时，高分画师行保持不变。没有这些键的 infotext（未使用画师串混合的生成，或旧版本只写了摘要的图片）不会改动面板。图库下方的发送按钮也会像其他 Anima 面板一样，把面板从文生图带到图生图。

## 推荐默认值

- 优化预设：`平衡`
- 组合模式：`输出平均`
- 融合模式：`插值融合`
- 全局画师强度：`0.70`
- 默认层数（2B 布局，见行控制）：平衡和质量 `0-51`（全部层），性能 `10-18`。
- 如果插值融合对某个提示词太强，再切到 `保真增量`。

## 注意

Anima 使用非线性的 LLM 文本编码器，因此无法做到 SDXL 画师混合那种近似无损。这个插件的目标是降低画师标签之间的上下文干扰，让风格混合更可控。

不支持含 `AND`（Forge 的多子提示组合）的提示词：Forge 会把每个子提示作为单独的条件块运行，把画师混入每个块会破坏 AND 组合。遇到这种情况插件在该遍不做混合，图片照常生成，infotext 记为 `Anima Artist Mixer: disabled: AND prompts are not supported`。

插件只在每次模型调用期间覆盖 Anima cross-attention，调用结束（包括出错）后立即还原原始 forward；不会修改文本编码器层或模型文件。
